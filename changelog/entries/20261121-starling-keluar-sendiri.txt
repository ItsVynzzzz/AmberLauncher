! Starling tidak lagi keluar sendiri ke layar utama saat game baru dibuka di HP yang lambat. Sebabnya menu sudah tampil sebelum sumber daya dunia selesai dimuat (terutama dengan Batas pekerja chunk = 1); sekarang mesin menunggu pemuatan itu selesai, dan mencatat di log bagian kode yang memintanya terlalu cepat.
[en]
! Starling no longer quits by itself back to the home screen when the game has just opened on a slow phone. The menu was shown before the world resources finished loading (especially with Chunk worker limit set to 1); the engine now waits for that loading to finish, and logs which part of the code asked for it too early.
