! Layar crash tidak lagi asal menyalahkan RAM. "Memori (RAM) HP habis" kini hanya muncul bila ada buktinya (Android mencatat HP kehabisan memori, atau log menyebut gagal meminta memori ke sistem). Kode keluar 137 saja tidak lagi dianggap masalah RAM.
+ Penjelasan crash baru: "Memori game (Java) habis" (bukan berarti RAM HP kurang) dan "Game dihentikan mendadak" (misalnya ditutup dari luar atau dimatikan penghemat baterai).
~ Tombol "Turunkan RAM" hanya ditawarkan saat HP benar-benar kehabisan memori. Detail teknis dan teks untuk AI kini memuat catatan Android tentang sebab proses game berhenti (Android 11 ke atas).
[en]
! The crash screen no longer blames RAM by default. "Phone memory (RAM) ran out" now appears only when there is evidence (Android recorded the phone running out of memory, or the log says a memory request to the system failed). Exit code 137 alone is no longer treated as a RAM problem.
+ New crash explanations: "Game (Java) memory ran out" (it does not mean the phone has too little RAM) and "Game stopped suddenly" (for example closed from outside or killed by battery saver).
~ The "Lower RAM" button is offered only when the phone really ran out of memory. Technical details and the text for AI now include Android's note on why the game process stopped (Android 11 and up).

! Màn hình crash không còn mặc định đổ lỗi cho RAM. "Hết bộ nhớ (RAM) của điện thoại" giờ chỉ hiện khi có bằng chứng (Android ghi nhận điện thoại hết bộ nhớ, hoặc nhật ký cho thấy yêu cầu cấp bộ nhớ từ hệ thống thất bại). Riêng mã thoát 137 không còn bị coi là lỗi RAM.

! 崩溃界面不再默认归咎于 RAM。只有在有证据时才会显示“手机内存（RAM）耗尽”（Android 记录到手机内存不足，或日志显示向系统申请内存失败）。单凭退出码 137 不再被视为 RAM 问题。
