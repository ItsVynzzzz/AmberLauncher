+ Tombol menu di game kini berbentuk pil: ikon gerigi membuka menu, ikon mata menyembunyikan atau menampilkan UI. Menu tetap bisa dibuka walau UI sedang disembunyikan, jadi tidak perlu menampilkan UI dulu saat streaming. Ukuran dan letaknya diatur di editor kontrol.

+ Semua overlay Streamer punya penggeser posisi mendatar dan tegak, serta tombol Gandakan.
~ Mode streamer tidak lagi menaruh tombol ">" di tepi layar. Overlay dinyalakan dan disembunyikan lewat menu dalam game (ikon gerigi).
! Tombol volume, daya, dan media tidak lagi menyembunyikan kontrol di layar seperti keyboard fisik.
[en]
+ The in-game menu button is now a pill: the gear icon opens the menu and the eye icon hides or shows the UI. The menu can be opened even while the UI is hidden, so there is no need to show the UI first while streaming. Its size and position are set in the controls editor.
+ Web overlays can now be dragged and resized right on screen (Arrange on screen), with quick box presets and a page scale in Settings, so a cut-off alert can be shrunk to fit.
+ Every Streamer overlay has horizontal and vertical position sliders and a Duplicate button.
~ Streamer mode no longer puts a ">" handle on the screen edge. Overlays are turned on and off from the in-game menu (gear icon).
! Volume, power, and media keys no longer hide the on-screen controls the way a physical keyboard does.

[zh]
+ 游戏内的菜单按钮现在是胶囊形：齿轮图标打开菜单，眼睛图标隐藏或显示界面。即使界面被隐藏也能打开菜单，直播时无需先显示界面。大小和位置可在控制编辑器中调整。
+ 网页叠加层现在可以直接在屏幕上拖动和调整大小（在屏幕上调整），设置中提供快速选框和页面缩放，被截断的提醒可以缩小到合适大小。
+ 每个 Streamer 叠加层都有水平和垂直位置滑块，以及复制按钮。
~ 直播模式不再在屏幕边缘放置“>”把手。叠加层通过游戏内菜单（齿轮图标）开启和隐藏。
! 音量键、电源键和媒体键不再像实体键盘那样隐藏屏幕上的控制按钮。
